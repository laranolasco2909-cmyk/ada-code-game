# ADA CODE — O Caminho das Instruções

Jogo educativo curto para a feira: organize até sete comandos e leve a máquina até a estrela em um tabuleiro 5×5.

## Acesso público

- Repositório: https://github.com/laranolasco2909-cmyk/ada-code-game
- Site do jogo (GitHub Pages): https://laranolasco2909-cmyk.github.io/ada-code-game/

O site é estático e funciona diretamente no celular, sem cadastro ou instalação. O endereço acima pode ser usado para gerar o QR Code.

## Como jogar

1. Escolha Avançar, Direita, Esquerda ou Voltar.
2. Monte uma sequência de até sete comandos.
3. Pressione Executar.
4. Se a máquina bater em um obstáculo, pressione Limpar e tente novamente.

## Publicação

O projeto usa HTML, CSS e JavaScript puros e está preparado para publicação pelo GitHub Pages a partir da branch `main`.
